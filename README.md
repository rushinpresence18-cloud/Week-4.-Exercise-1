# Week-4.-Exercise-1
Project Description

This project contains beginner-friendly JavaScript functions that perform different tasks such as calculations, string manipulation, vowel counting, and checking prime numbers.

Functions Included
1. Multiply Function

Multiplies 3 numbers together and checks that the numbers are not the same.

2. Convert To Seconds

Converts minutes into seconds.

3. Fahrenheit To Celsius

Converts temperature from Fahrenheit to Celsius.

4. Reverse String

Reverses a word or sentence.

5. Count Vowels

Counts how many vowels are in a word or sentence.

6. Prime Number Checker

Checks whether a number is prime or not.

JavaScript Concepts Used

Functions

Parameters and Arguments

Loops

Open Visual Studio Code.
